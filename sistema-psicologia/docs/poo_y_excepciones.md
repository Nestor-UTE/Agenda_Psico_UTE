# Documentación de POO y Manejo de Excepciones

## 1. Programación Orientada a Objetos (POO)

Para desarrollar el sistema se utilizó la Programación Orientada a Objetos, que consiste en organizar el código mediante clases. En este proyecto se crearon clases para representar los diferentes elementos del sistema, como Alumnos, Citas, Tutores, Psicóloga, Seguimiento y Ubicación. Esto ayuda a tener el código más ordenado y facilita realizar cambios o corregir errores sin afectar todo el sistema.

## 2. Manejo de Excepciones y Control de Errores

Para evitar que la aplicación presente fallas o deje de funcionar cuando ocurre algún problema, se implementó un manejo de errores. Esto se utiliza principalmente al momento de conectar con la base de datos MySQL o guardar información. Si ocurre algún problema, como un error de conexión o datos incorrectos, el sistema puede identificarlo y mostrar un mensaje de aviso al usuario en lugar de cerrar o dejar de funcionar la página.
